## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/PoundEnsign.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

PoundEnsign is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
